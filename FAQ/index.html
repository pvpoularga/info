Perguntas Frequentes

Encontra aqui as respostas às dúvidas mais comuns sobre o servidor.

COMANDOS DO SERVIDOR

/id - Mostra o teu ID único.
/players - Abre a lista de jogadores online.
/report (mensagem) - Envia um pedido à staff. Só permite um report ativo.
/clear - Limpa o teu chat.
/transferpoints [ID] [quantidade] - Transfere pontos para outro jogador.
/revistar - Revista um jogador morto próximo, fora da safezone.
/reviver - Inicia a reanimação de um membro da tua crew próximo, fora da safezone.
/zombie - Ativa/desativa o spawn dos teus zombies; ao desativar, remove os existentes.
/tunar - Abre o tuning, exige estar dentro de um veículo na safezone.
/peds - Abre o menu de peds.
/fps - Liga/desliga a otimização gráfica.

TECLAS DEFAULT

T - Abre o chat.
L - Mostra/esconde o chat.
TAB - Abre/fecha o inventário.
H - Desiste no ecrã de morte, perdendo o loot.
Z - Marca o ponto para onde estás a apontar, visível para membros da mesma crew.
K - Guarda o veículo que atual.

Como crio binds?

bind keyboard "key" "command" - Cria um bind para o comando desejado, substituindo "key" pela tecla e "command" pelo comando.
Exemplo: bind keyboard "F5" "revistar"
