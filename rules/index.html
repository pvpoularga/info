REGRAS GERAIS

● Proibidos insultos discriminatórios, perseguição, ameaças reais ou divulgação de dados pessoais.
● Proibido usar mais do que uma conta para contornar bans ou obter vantagens.
● Proibido usar cheats, macros ou explorar bugs.
● Proibido fazer-se passar por membros da staff.
● Proibido o uso de nomes, apelidos ou tags ofensivas.
● Proibido vender contas, personagens ou itens do servidor (RMT).

PVP

● Proibido jogar nas extremidades das Safe Zones.
● Proibido o uso de veículos para entrar ou obstruir entradas a locais fechados.
● Proibido o uso de personagem inicial.
● Proibido deluxo trick.
●

MODS PROIBIDOS

● Ped Glow
● Low Mesh
● Modificações, ficheiros ou ferramentas que removam, ocultem ou alterem edifícios, paredes ou as respetivas colisões, permitindo visualizar ou atravessar estruturas que normalmente impedem a visão ou a passagem.
●
●

SERVIÇOS OBRIGATÓRIOS

● Running PcaSvc
● Running CDPSvc
● Running DPS
● Running SSDPSRV
● Running DiagTrack
● Running EventLog
● Running SysMain
● Running CDP

Se algum destes serviços estiver parado durante o PC check resultará em ban do servidor.
